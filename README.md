## AI Engineer Intern - Technical Assessment

Welcome to my submission for the AI Engineer Intern technical assessment. This repository contains two projects, each addressing a separate technical assessment for building a weather app with AI/ML/Gen AI applications. Navigate to the respective folders for detailed exploration:

- **[Tech_Assessment_1]**: Code, README, and demo for a weather app that retrieves real-time weather data based on user-input locations, with optional features like a 5-day forecast and current location support.

## Description

**Objective**: Build a weather app that processes user input, fetches real-time data from external APIs, and delivers meaningful weather insights. The assessments evaluate technical skills, creative problem-solving, and user-centric design.

### Overview

- **Tech Assessment 1**: A functional weather app accepting inputs like Zip Code, GPS Coordinates, or City to display current weather data. Optional features include a 5-day forecast, current location support, and visual weather icons.
- **Tech Assessment 2**: Extends the app with advanced features, including mandatory CRUD operations (Create, Read, Update, Delete) using a database, input validation, and optional integrations like YouTube, Google Maps, or data export (JSON, CSV, PDF).

### Key Considerations

- User-guided input with validation and database storage (for Tech Assessment 2).
- Creative solutions for user needs (e.g., travelers checking weather).
- Tech Assessment 1 is mandatory; Tech Assessment 2 is optional but completed to showcase advanced capabilities.
